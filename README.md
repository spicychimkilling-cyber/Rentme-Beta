## Rentme-Beta

Rentme-Beta is a beta-stage web application for a local rental marketplace.

The platform is designed to help users list, browse, and manage rental items within a community, making local renting more accessible and organized.

This project focuses on building a clear and scalable front-end architecture that can be extended into a full peer-to-peer rental system.

The application is built with modern web technologies and uses a lightweight development setup for fast iteration.

## Tech Stack

TypeScript is used for application logic and structure.

HTML is used for defining the layout and content.

CSS is used for styling and responsive design.

Vite is used for development and build tooling.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
